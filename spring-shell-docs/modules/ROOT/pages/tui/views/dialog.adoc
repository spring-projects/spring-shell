[[tui-views-dialog]]
= DialogView
:page-section-summary-toc: 1

ifndef::snippets[:snippets: ../../../../../src/test/java/org/springframework/shell/docs]

_DialogView_ is a base implementation providing functionality to draw a dialog.
_DialogView_ inherits from xref:tui/views/box.adoc[].

[source, text]
----
┌──────────────────┐
│                  │
│  <Main content>  │
│                  │
├──────────────────┤
│    <Buttons>     │
└──────────────────┘
----

== Default Bindings
Does not have any default bindings.

== Events
An event is sent when the dialog is requested to close.

.DialogView Events
|===
|Event |Description

|DialogViewCloseEvent
|The dialog is requested to close.

|===
